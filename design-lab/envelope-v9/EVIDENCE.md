The first standalone-copy smoke then found a real core accessibility bug. An encoded source such as `&amp;` was normalized to `&` for visible vector geometry but could be escaped again from the encoded source for `aria-label` / `<title>`. The vector kernel now derives accessibility metadata from the same decoded visible string used for glyph geometry. This makes visible and semantic text agree and prevents double escaping.

## Negative proof lineage retained

Three P3 failures remain useful harness evidence:

- asynchronous `--dump-dom` serialized before an async receipt was populated; this was a harness race, not render evidence;
- `SVGSVGElement.setCurrentTime()` + `getCTM()` produced no useful timeline delta in the inline harness; it was replaced by persistent Chrome + real elapsed time + screenshot pixel diffs;
- parent-target-only CDP reduced-motion emulation reported `reduce=true` on the page while separately decoded external SVG images still moved. Browser-wide `--force-prefers-reduced-motion` is the accepted external-image proof and produces 0/0 changed rail pairs.

P4 adds one successful failure mode: the standalone-copy test exposed accessibility double escaping that the donor-only matrix had not discriminated. This is exactly why extraction readiness is validated in a copied tree rather than inferred from repository-local success.

## Relationship to v8 public evidence

Envelope v8 already has actual-public-profile evidence for 8 non-hero documents / 14 rail strips. v9 does not inherit that result wholesale. It proves exact inherited motion-subtree equivalence plus local v9 rendering/playback. A public v9 playback claim still requires intentionally mounting v9 on a stable public target and observing that target separately.

## Claim boundary

Established:

- deterministic target-sensitive generated-output fingerprint;
- real-Chrome light/dark and desktop/mobile rendering for the tested matrix;
- font-independent safe visible text for the supported glyph set;
- screenshot-backed transparent host-background exposure;
- local isolated v9 rail playback, reduced-motion silence and motion-off silence;
- exact inherited motion-subtree equivalence to v8;
- a five-file stdlib-only standalone-copyable kernel with owner-independent Schema identity;
- schema/implementation alignment and decoded accessibility metadata for vector text.

Not established:

- v9 is live;
- public GitHub-profile v9 playback;
- shared runtime clocks or frame-perfect cross-document synchronization;
- universal typography quality for all future glyphs/data densities;
- the current donor-bound renderer is a standalone public package;
- a second independent consumer exists;
- a standalone `profile-envelope` Skill is justified.
